The problem with "autonomous DS agents"

🤖

They overreach

Demos pretend the whole pipeline runs unattended. Reality hits — schema drift, a weird column, a flaky library — and they crash opaquely.

📦

One-shot outputs

When they "work," the result is a zip of code + charts. No PR, no review, no incremental history you can trust.

🔁

Restart culture

Every run starts from zero. Nothing compounds. Humans can't pick up where the agent left off, and vice-versa.

🤝

DS is collaborative

What's needed is a teammate — works on individual tickets, respects your WIP, lets you review.

Cortex is a teammate,
not an autonomous agent.

1 issue = 1 run = 1 PR

Shared backlog

You and Cortex pull from the same GitHub issues. Nobody collides.

Human owns merge

Cortex opens PRs. You review and merge like for any colleague.

Fail loud

Real blockers surface immediately. No "are you sure?" on trivia.

Two human breakpoints

Plan (should Cortex actually do this?) and post-model (metrics worth merging?). Everything else runs unattended.

Postgres checkpointer

Resume after approval is just graph.invoke(None). State survives redeploys, partial failures, restarts.

Anti-loop guards

Re-entering modeling after an approval is blocked. Review loop capped. No infinite token burn.

Issue context flows through

Triggering issue number carries in state, so node_report can close it at the end.

Deterministic reports

LLM writes decisions

Classification, narrative, hypothesis selection, metric rationale — the stuff that needs judgement.

Repo writes structure

Quarto templates pinned at templates/*.qmd. The agent produces summary.json; the template renders it.

Result: every run yields the same shape of HTML output. Diff reports across runs. Schema changes are reviewable in Git.

Concurrency model

Teammate-safe: humans and Cortex share the same backlog without stepping on each other.

🏷️

Claim via label

Adding cortex:in-progress is the lock. Label absent = claimable. Atomic enough for GitHub's eventual consistency.

⏱️

ISO lease timestamp

Comment on the issue with lease-until: <ts>. Future sweeper reclaims orphaned leases.

🏁

Race detection

Re-read the issue right before writing. If someone claimed in the window, back off with status: skipped.

🧹

Release on exit

End of run: remove label + close issue. If push failed: release only (leave open to retry).

Takeaways

Collaborator, not autonomous. The human always owns the merge.
Structure in the repo, decisions in the LLM. Templates pinned; prompts change.
Explicit intent > smart defaults. auto_create_repo is asked for, never inferred.
Fail loud. Don't ask for approval on trivia.
